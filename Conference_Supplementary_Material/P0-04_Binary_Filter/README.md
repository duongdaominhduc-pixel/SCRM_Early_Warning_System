# Phase 0-04: Binary Filter (Gatekeeper)

## 1. Objective
This phase functions as the Sensing layer within the Early Warning System (EWS) for Supply Chain Risk Management (SCRM). The objective is to construct a "Gatekeeper" using a binary classification model to filter unstructured news data.
- **Class 0 (NO_RISK):** Standard news articles containing no supply chain risks.
- **Class 1 (RISK):** Articles containing potential supply chain disruptions.
